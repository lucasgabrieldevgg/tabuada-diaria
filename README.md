# Tabuada Diária (Daily Times Tables)

> Study and master multiplication — a daily times-table trainer in a single HTML file. No build step, no dependencies, works offline.

**Live demo:** https://tabuada-diaria.vercel.app

## ✨ Features

- ➗ **Times table practice** from 1 to 10 with instant feedback
- 📅 **Daily session** logic to build a study streak
- 📊 **Score tracking** per table
- 📱 **Responsive** — works on phones and desktops
- 📄 **Single file** — everything lives in `index.html`

## 📦 Run locally

Just open `index.html` in a browser, or serve it with any static server.
